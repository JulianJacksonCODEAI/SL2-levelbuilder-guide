# Blocks

Every block a Sprite Lab 2 level can offer in its toolbox: what it looks like, its type, what it does, and whether it worked in a test run. Tested 2026-11-25 in a start-mode preview; nothing was saved. Pictures switch with the site's light and dark theme.

| Label | Meaning |
|---|---|
| <span class="status tested">Tested</span> | Ran in a test program and did what the row says. |
| <span class="status untested">Check by hand</span> | Couldn't be checked in the test (needs arrow keys, sound, or songs). The note says why. |
| <span class="status untested">Not yet tested</span> | Reported or read from the lab's code, not tried yet. |
| <span class="status no">Not available</span> | Not in Sprite Lab 2. See [Not in Sprite Lab 2](#not-in-sprite-lab-2). |

The code next to each block's name is its type: the name used in level JSON and console snippets. To link to a block, add `#` and its type to this page's address, for example `blocks/#spritelab2_askAI`. **Details** shows the block's shape and test notes.

!!! tip "Testing a block yourself"
    In start mode the small preview runs **when run** right away, so you can see most blocks work without pressing Run. Timers, clicks and behaviors need **Run**. The game takes about 3 seconds to start.
