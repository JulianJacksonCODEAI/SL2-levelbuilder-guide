# Sprite Lab 2 Level Builder Guide

This guide shows curriculum writers how to build **Sprite Lab 2** (also called Lab2 Sprite Lab) levels in Code.org Level Builder.

Most pages were tried in Level Builder on **2026-11-24**. Pages tested later, such as [Blocks](reference/blocks.md), give their own date. Sprite Lab 2 changes often, so check the date before relying on a detail.

## How to read the status labels

| Label | Meaning |
|---|---|
| <span class="status tested">Tested</span> | Tried in Level Builder and did what the page says. |
| <span class="status untested">Check by hand</span> | Couldn't be checked in a test run (it needs arrow keys, sound or songs). The note says why. |
| <span class="status unverified">Not yet tested</span> | Comes from the lab's code or a report. Try it on your own test level first. |
| <span class="status no">Not available</span> | Not in Sprite Lab 2 yet. |

## Start here

- New to Sprite Lab 2? Read **[Make a level](make-a-level.md)**, then **[Level modes](level-modes.md)**.
- Setting up what students start with? Go to **[Starter code and toolbox](starter-code-and-toolbox.md)**.
- Checking student progress? Sprite Lab 2 uses **[Checklists](checklists.md)** instead of the old JavaScript validation.
- Using the AI blocks? See **[AI blocks](reference/ai-blocks.md)** for what they return when things go wrong.
